# Asset provenance / Происхождение изображений

The badges are original GitHub artwork, preserved locally so Markdown renders without relying on old image URLs. The origin and retrieval date of every downloaded image are recorded in [manifest.json](manifest.json).

Значки — оригинальные изображения GitHub. Они сохранены локально, чтобы каталог не зависел от старых URL. Источник и дата загрузки каждого изображения указаны в [manifest.json](manifest.json).

`badges/` contains default and tier designs. `variants/` contains skin-tone artwork. `legacy/` contains the original 2021–2022 designs, preserved from the public historical archive by [Schweinepriester](https://github.com/Schweinepriester/github-profile-achievements). A mirrored historical file is identified in the manifest.

`evidence/` contains the two unmodified screenshots supplied for this update: JakubOleksy’s Proxima Pioneer and Proxima Staffshipper dialogs. They corroborate the profile records and are distinct from reusable badge artwork.

В `evidence/` находятся два исходных скриншота пользователя без изменений. Они подтверждают карточки наград и не используются как отдельные значки.

GitHub owns its badge artwork and trademarks. The repository’s CC0 text license does **not** relicense third-party images or screenshots. No new ownership or blanket permission is claimed for those assets.
